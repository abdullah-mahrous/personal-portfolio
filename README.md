# Abdullah Mahrous — Personal Portfolio

A modern, responsive personal portfolio built to present my work, experience, and technical capabilities as a Full Stack Developer.

---

## Overview

This portfolio is designed to showcase selected projects and provide a clear view of my development approach, tools, and the type of applications I build. It includes a structured projects section, detailed project pages, and a simple blog system to share ideas and technical content.

The goal of this project is to present my work in a professional, accessible way while maintaining a modern interface and intuitive navigation.
